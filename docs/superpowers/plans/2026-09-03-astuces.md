# Page d'astuces : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Créer `astuces.html`, une fiche mémo autonome donnant, pour chaque classe et chaque fonction grammaticale, un test concret de reconnaissance illustré de 3 à 5 exemples, plus des sections « Ne confonds pas » ; et la relier depuis `index.html`.

**Architecture:** Une page HTML statique unique (CSS et JS inline), calquée sur la structure des deux carnets : en-tête avec bouton Accueil, deux onglets (`nav[role=tablist]`), deux `section.panel` au contenu statique (pas de rendu JS, le contenu est écrit directement dans le HTML). Le seul JS est le changement d'onglet.

**Tech Stack:** HTML/CSS/JS vanilla, Google Fonts (Instrument Serif + Karla). Aucun build, aucune dépendance, aucun framework de test : la vérification se fait en ouvrant la page dans un navigateur.

## Global Constraints

- Tout le texte visible est en français ; messages de commit en français, présent de l'impératif ou de l'indicatif.
- Charte cahier : réutiliser les variables CSS des carnets (`--paper:#F5F6F1`, `--paper-2:#FCFCFA`, `--rule:#BFD3E4`, `--rule-soft:#DDE7F0`, `--marge:#DE5B4A`, `--ink:#16233B`, `--ink-soft:#5E6E85`, `--classes:#1D4E89`, `--fonctions:#1B6F55`), feuille lignée `repeating-linear-gradient`, marge rouge `::before`.
- Onglet Classes en bleu `--classes`, onglet Fonctions en vert `--fonctions` ; chaque catégorie garde sa couleur propre (copier les variables `--nom`, `--verbe`, etc. depuis `classes-grammaticales.html`, et les couleurs de fonctions depuis `fonctions-grammaticales.html`).
- Breakpoints 420 px et 360 px, `prefers-reduced-motion`, `:focus-visible`, cible principale : téléphone (max-width 560 px via `.wrap`).
- Pas de score, pas de confettis, pas d'appel à Google Sheets.
- Ne pas utiliser de tiret cadratin dans les textes.

### Task 2 : les 9 cartes de classes

**Files:**
- Modify: `astuces.html` (panneau `#classes`)

**Interfaces:**
- Consumes: classes CSS `.astuce`, `.cible` de la tâche 1 ; variables de couleur `--nom`, `--verbe`, `--adjectif`, `--determinant`, `--pronom`, `--adverbe`, `--preposition`, `--conjonction`, `--interjection` copiées du carnet 1.

- [ ] **Step 1 : écrire les 9 cartes** dans `#classes`, chacune sur ce modèle (le mot visé est entouré de `<em class="cible">`) :

```html
<article class="astuce" style="--c:var(--determinant)">
  <h2>Le déterminant</h2>
  <p class="truc"><strong>Il est suivi d'un nom</strong> (parfois avec un adjectif entre les deux). Il ne s'emploie jamais seul.</p>
  <ul class="ex">
    <li><em class="cible">Le</em> chat dort sur le muret.</li>
    <li><em class="cible">Cette</em> vieille maison me plaît.</li>
    <li><em class="cible">Mes</em> amis arrivent ce soir.</li>
    <li><em class="cible">Plusieurs</em> élèves ont fini.</li>
  </ul>
</article>
```

Contenu des 9 cartes (astuce, puis exemples avec la cible entre crochets) :
1. **Nom** : « On peut mettre *un, une, le, la* devant. Il désigne une personne, une chose, une idée ou une qualité. » Ex : Le [courage] de Léa m'étonne. / Cette [maison] est ancienne. / Le [rire] des enfants traversait la cour. / [Marseille] est un port méditerranéen (nom propre : majuscule, souvent pas de déterminant).
2. **Verbe** : « Il se conjugue : change la personne ou le temps, et c'est lui qui change. » Ex : Elle [chante] sous la douche (hier : elle chantait). / Nous [finirons] demain. / Il [rit] aux éclats (à ne pas confondre avec le rire). / [Prendre] son temps est un luxe (à l'infinitif aussi, c'est un verbe).
3. **Adjectif** : « Il s'accorde avec le nom, et on peut presque toujours dire *très...* devant. » Ex : une rue [bruyante], des rues [bruyantes]. / Il est très [gentil]. / des idées [claires]. / un film [passionnant].
4. **Déterminant** : voir le modèle ci-dessus.
5. **Pronom** : « Il remplace un nom ou un groupe nominal : aucun nom ne le suit. » Ex : [Il] dort sur le muret (= le chat). / Je [les] vois demain. / [Ceux] qui parlent sortiront. / Prends [le mien].
6. **Adverbe** : « Il est invariable et précise un verbe, un adjectif ou un autre adverbe. Beaucoup finissent en *-ment*. » Ex : Elles parlent [fort] (jamais « fortes » : pas d'accord). / Il court [vite]. / Elle est [très] contente. / [Lentement], la barque s'éloigne.
7. **Préposition** : « Petit mot invariable qui introduit un complément : *à, de, par, pour, en, vers, avec, sans, sous, sur, chez...* » Ex : le vélo [de] Paul. / Il part [pour] Lyon. / Elle réussit [sans] effort. / Viens [avec] nous.
8. **Conjonction** : « Elle relie deux mots ou deux propositions : *mais, ou, et, donc, or, ni, car*, et *que, quand, parce que, si...* » Ex : Il pleut [mais] je sors. / Je pense [que] tu réussiras. / Tu viens [ou] tu restes ? / [Quand] il pleut, on lit.
9. **Interjection** : « Mot-exclamation qui s'emploie seul, souvent suivi d'un point d'exclamation. » Ex : [Ah] ! te voilà enfin. / [Hélas], il est trop tard. / [Chut] ! on écoute.

### Task 3 : les 9 cartes de fonctions

**Files:**
- Modify: `astuces.html` (panneau `#fonctions`)

**Interfaces:**
- Consumes: mêmes classes CSS ; variables de couleur des fonctions copiées du carnet 2 (`--sujet`, `--cod`, `--coi`, `--attribut`, `--cc`, `--epithete`, `--cdn`, `--apposition`, `--agent`, reprendre les noms exacts du carnet 2).

- [ ] **Step 1 : écrire les 9 cartes** dans `#fonctions`, même modèle que la tâche 2 :
1. **Sujet** : « Pose la question *qui est-ce qui... ?* devant le verbe, ou encadre par *c'est... qui*. » Ex : [Ma sœur] chante dans un groupe (c'est ma sœur qui chante). / [Le vent] souffle depuis ce matin. / Demain partiront [les invités] (sujet inversé). / [Lire] me détend.
2. **COD** : « Verbe + *qui ?* ou *quoi ?*, sans préposition. On peut le remplacer par *le, la, les*. » Ex : Je lis [ce roman] (je le lis). / Elle appelle [son frère]. / Nous voulons [partir]. / Il dit [qu'il viendra].
3. **COI** : « Verbe + *à qui ? à quoi ? de qui ? de quoi ?* On peut le remplacer par *lui, leur, en, y*. » Ex : Il parle [à sa voisine] (il lui parle). / Elle se souvient [de ce voyage] (elle s'en souvient). / Je pense [à toi]. / Ils doutent [de sa réponse].
4. **Attribut du sujet** : « Après un verbe d'état (*être, sembler, devenir, paraître, rester...*), il dit ce qu'est le sujet. » Ex : Elle est [médecin]. / Le ciel devient [sombre]. / Ils semblent [fatigués]. / Ce quartier reste [calme].
5. **CC** : « On peut le déplacer et le supprimer. Il répond à *où ? quand ? comment ? pourquoi ?* » Ex : [Ce soir], nous sortons (nous sortons ce soir ; nous sortons). / Il travaille [dans sa chambre]. / Elle marche [d'un pas rapide]. / [Pour réussir], il s'entraîne.
6. **Épithète** : « Adjectif collé au nom, avant ou après lui, dans le groupe nominal. » Ex : une [longue] route. / un chat [noir]. / des vacances [inoubliables]. / ce [vieux] pont de pierre.
7. **CDN** : « Il complète un nom et il est introduit par une préposition, le plus souvent *de*. » Ex : le vélo [de Paul]. / une tasse [à café]. / la peur [du vide]. / un billet [pour Rome].
8. **Apposition** : « Détachée par des virgules, elle désigne la même chose que le nom qu'elle précise. » Ex : Paris, [capitale de la France], attire des millions de visiteurs. / [Épuisée], elle s'endormit aussitôt. / Mon frère, [grand rêveur], oublie tout.
9. **Complément d'agent** : « Dans une phrase passive, il est introduit par *par* (ou *de*) : c'est lui qui fait vraiment l'action. » Ex : Le tableau fut peint [par un élève de Rubens]. / La souris est chassée [par le chat]. / Elle est appréciée [de tous].

### Task 4 : sections « Ne confonds pas »

**Files:**
- Modify: `astuces.html` (bas des panneaux `#classes` et `#fonctions`)

**Interfaces:**
- Consumes: classes CSS `.section-title`, `.vs` de la tâche 1. Dans une paire, chaque exemple colore sa cible avec la couleur de sa propre catégorie via `style="--c:var(--adverbe)"` posé sur le `<em class="cible">`.

- [ ] **Step 1 : bas de l'onglet Classes.** Titre `<p class="section-title">Ne confonds pas</p>` puis 4 blocs `.vs` :
1. **Adverbe ou adjectif ?** « L'adverbe ne s'accorde jamais ; l'adjectif s'accorde avec le nom. » Ex en miroir : Elles parlent [fort] (adverbe, invariable) / Elles sont [fortes] (adjectif, accord). / Ces fleurs sentent [bon] / Ces fleurs sont [bonnes]. / Ils travaillent [dur] / Des exercices [durs]. / Elle chante [juste] / Des réponses [justes].
2. **Déterminant ou pronom ?** « Suivi d'un nom : déterminant. Devant un verbe ou employé seul : pronom. » Ex : [La] porte claque (dét.) / Je [la] ferme (pron.). / [Leur] chien aboie / Je [leur] parle. / [Ce] livre me plaît / [Ce] n'est pas grave.
3. **Nom ou verbe ?** « S'il se conjugue, c'est le verbe ; s'il suit un déterminant, c'est le nom. » Ex : Le [rire] des enfants / Il [rit] aux éclats. / Le [dîner] refroidit / Nous [dînons] tard. / Son [travail] avance / Elle [travaille] le soir.
4. **Préposition ou conjonction ?** « La préposition introduit un mot ou un groupe ; la conjonction relie, et *car, que, quand* annoncent un verbe conjugué. » Ex : Il reste [pour] la nuit / Il reste [car] il pleut. / Elle sort [sans] parapluie / Elle sort [quand] il fait beau. / Un gâteau [à] partager / Je crois [que] tu aimeras.

- [ ] **Step 2 : bas de l'onglet Fonctions.** Même titre puis 3 blocs `.vs` :
1. **COD ou attribut du sujet ?** « L'attribut suit un verbe d'état et parle du sujet ; le COD suit un verbe d'action et désigne autre chose. » Ex : Elle est [médecin] (attribut) / Elle appelle [un médecin] (COD). / Il devient [un champion] / Il bat [un champion]. / Ce plat semble [délicieux] / Elle prépare [un plat délicieux].
2. **CC ou COI ?** « Le CC se déplace et se supprime ; le COI est réclamé par le verbe et ne se supprime pas. » Ex : Elle parle [avec douceur] (CC : Elle parle) / Elle parle [à sa mère] (COI : « Elle parle » ne dit plus à qui). / Il pense [à son avenir] (COI) / Il lit [dans le jardin] (CC). / Nous jouons [depuis midi] (CC) / Nous jouons [de la guitare] (COI).
3. **Épithète ou attribut ?** « L'épithète est collée au nom ; l'attribut en est séparé par un verbe d'état. » Ex : la mer [calme] / La mer est [calme]. / un enfant [sage] / Cet enfant paraît [sage]. / une rue [déserte] / La rue restait [déserte].
